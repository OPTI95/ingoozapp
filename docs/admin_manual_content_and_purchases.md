# Ingooz — Инструкция администратора (контент и покупки)

## 1. Доступ администратора

Админ-доступ определяется флагом `profiles.is_admin = true`.

Проверка:

```sql
select user_id, is_admin
from public.profiles
where user_id = '<USER_ID>';
```

## 2. Контент (Памятка / PDF)

Раздел: `Памятка` (`/guide`)

### Что может админ

- Загрузить новый PDF (`Добавить PDF`)
- Удалить PDF
- Открыть/поделиться PDF

### Требования к файлам

- Формат: только `.pdf`
- Имя файла задаётся при загрузке
- Файл хранится в таблице `guide_files` (base64)

### Проверка после загрузки

1. Открыть `/guide` под обычным пользователем.
2. Убедиться, что новый файл виден.
3. Проверить открытие/шаринг файла.

## 3. Управление покупками / оплатами

Раздел пользователя: `Пополнение баланса` (`/payment-methods`)  
Edge Functions: `tinkoff-init`, `tinkoff-notify`.

### Как работает

1. Пользователь вводит сумму (минимум 100 ₽).
2. Приложение создаёт `pending` запись в `payments`.
3. Пользователь уходит на страницу оплаты Tinkoff.
4. После webhook `tinkoff-notify` статус платежа обновляется:
   - `succeeded` — успешно
   - `failed` / `canceled` — неуспешно
5. При успешной оплате обновляется баланс в `profiles`.

### Что админ контролирует

- Корректность статусов в `payments`
- Рост `profiles.balance` после `succeeded`
- Работу webhook в логах Edge Functions

### SQL для оперативной проверки

```sql
-- Последние платежи
select id, user_id, amount, currency, status, provider, provider_payment_id, created_at, updated_at
from public.payments
order by created_at desc
limit 50;

-- Баланс пользователя
select user_id, full_name, phone, balance
from public.profiles
order by balance desc
limit 50;
```

## 4. Управление промокодами (квоты)

Раздел: `Админ: промокоды` (`/admin-promo`)

### Что можно делать

- Создать промокод
- Изменить параметры (код, квота, лимит активаций, срок, активность)
- Отключить промокод
- Удалить промокод и связанные активации

### Ключевые поля

- `waybill_quota` — сколько путевых листов даёт код
- `max_redemptions` — лимит пользователей, которые могут активировать код
- `expires_at` — срок действия
- `is_active` — активность

## 5. Настройки штампов и цены

Раздел: `Настройки печатей` (`/admin-stamps`)

### Что редактируется

- Тексты техконтроля / медосмотра
- Подпись под медосмотром
- ОКПО
- `waybill_price` (цена путевого листа)

Хранится в таблице `stamps` в формате `key/value`.

## 6. Типовые инциденты и действия

### Платёж не зачислился

1. Найти запись в `payments` по `provider_payment_id`.
2. Проверить логи `tinkoff-notify`.
3. Проверить факт обновления `profiles.balance`.

### Пользователь не может зарегистрироваться по телефону

1. Проверить `phone_otps` (создание, attempts, verified, call_count).
2. Проверить логи функции `sms-auth`.
3. Убедиться, что пользователь вводит код и нажимает подтверждение.

## 7. Рекомендации по эксплуатации

- Проверять Edge Functions логи ежедневно.
- Раз в неделю смотреть ошибки платежей и недозвоны phone auth.
- Ограничить круг админов и периодически ревизовать `profiles.is_admin`.
